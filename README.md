# Employee Satisfaction Analysis Dashboard (Excel)

## Project Overview

This project analyzes employee survey responses using Excel Pivot Tables, Charts, KPI Cards, and Slicers to identify satisfaction trends and generate business insights.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design

## Key Insights

* Sheriff's Department recorded the lowest satisfaction score (2.39), indicating potential workplace concerns.
* Family Justice Center achieved the highest satisfaction score (3.51), reflecting positive employee sentiment.
* Staff employees reported lower satisfaction compared to leadership roles.

## Dashboard Features

* Department vs Average Satisfaction
* Role vs Average Satisfaction
* Response Distribution
* KPI Cards
* Interactive Slicers

Data Cleaning | Data Analysis | Dashboarding | Excel | Business Insights
